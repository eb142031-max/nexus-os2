# Dark Leyla OS — Vault Studio

A standalone, dependency-free development UI prototype for the Dark Leyla creative workspace.

## Preview scope

- Command Deck, Persona Forge, Storyboards, NEO-AI Scene Lab, Render Queue, Asset Vault, and Hall 5 Review.
- Responsive layout and local-only UI interactions.
- Procedural CSS display object with orbit rotation and lighting preset controls.

## Explicit limitations

This is a front-end prototype only. It has no authentication, database, asset upload, model-provider connection, image/video generation, durable audit ledger, or publishing integration. Sample counts and sample records are illustrative, not telemetry. Browser controls do not grant consent, rights, age, identity, or execution approval.

## Local preview

Open `index.html` directly in a modern browser. No package installation or external CDN is required.
